## The Roadmap: From Raw Data to AI

This repository is structured into 5 logical phases, mirroring the true lifecycle of data in a modern enterprise:

### [01_Core_Python_SQL](./01_Core_Python_SQL) : The Foundations
> Building the bedrock of reliable data. 
* **Tech:** Python (Pandas), SQL (PostgreSQL/MySQL)
* **Focus:** Advanced data wrangling, complex querying, and writing clean, efficient code to manipulate unrefined datasets.

### [02_BI_Reporting](./02_BI_Reporting) : Translating Numbers into Narratives
> Turning complex datasets into intuitive, actionable business insights.
* **Tech:** Power BI, Tableau, Qlik Sense
* **Focus:** Dimensional data modeling (DAX) and designing dashboards that track financial performance and key business KPIs.

### [03_Modern_Data_Stack](./03_Modern_Data_Stack) : Cloud & Transformation
> Engineering robust data workflows for the cloud era.
* **Tech:** Snowflake, dbt (data build tool)
* **Focus:** Modern ELT processes, CI/CD for data pipelines, and rigorous data quality testing to ensure stakeholders can trust their data.

### [04_Ingestion_Ecosystems](./04_Ingestion_Ecosystems) : Keeping Data in Motion
> Moving data securely and efficiently across complex systems.
* **Tech:** Apache NiFi, Microsoft Fabric
* **Focus:** Real-time data ingestion, automated pipeline orchestration, and unified platform management.

### [05_BigData_AI](./05_BigData_AI) : Unlocking Future Value
> Scaling operations and leveraging data to predict future trends.
* **Tech:** Databricks (Spark), Python (PyTorch, Scikit-learn)
* **Focus:** Lakehouse architectures and building predictive models tailored to finance and consulting (e.g., fraud detection, dynamic pricing).
